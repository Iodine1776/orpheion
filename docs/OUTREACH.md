# Orpheion outreach

Copy-paste templates for agency outreach. Send from `hello@orpheion.com` as **plain text** (or very light formatting — no HTML newsletter look).

---

## Email styling tips

| Do | Don’t |
| --- | --- |
| Plain Gmail compose, default font | Fancy templates, colored backgrounds, big logos in the body |
| Short paragraphs (1–2 sentences) | Long “about me” stories |
| One clear ask | Attach PDFs / rate cards on first touch |
| Personalize 1 line (their recent work / “not web developers”) | Mass-mail merge that feels spammy |
| Link the site once | Five links + Calendly in the first email |

**Also set in Gmail (Workspace):**

- **Name:** Sam Bolton or `Sam Bolton | Orpheion`
- **Reply-to:** `hello@orpheion.com`
- Turn **off** “Confidential mode” / tracking pixels if any
- Optional: Gmail label `Outreach` for sent pitches

No social icon rows, no “Sent from my iPhone,” no legal disclaimer walls in the signature.
