# Orpheion — Master Plan

**Orpheion** is an async, productized design-to-production studio: locked design files in, live Next.js out.

> Commercial brand: **Orpheion**  
> Founder story (About only): Orpheus — craft that crosses a hard boundary and returns something living.  
> Do not market as “Orpheus” (name collision with existing web agencies).

---

## 1. Vision & constraints

| | |
| --- | --- |
| **Core offer** | Productized subscription: one active production request at a time from locked Figma (or equivalent) |
| **Buyer** | Design agencies / brand studios with overflow (design-ready clients only) |
| **Income goals** | Always **net take-home** (after tax reserve + overhead) |
| **Time** | 8–12 hrs/week in async pockets; **no Zoom by default** |

## 4. Technical stack (assembly line)

```
Figma (locked) → Cursor (Agent) → Next.js + Tailwind (+ Shadcn) → Vercel
                                      forms: SaaS / light hosted path
```

- **Framework:** Next.js (App Router), TypeScript  
- **UI:** Tailwind CSS, Shadcn where appropriate, Framer Motion only when designed  
- **Hosting:** Vercel  
- **Backend:** Not default. Supabase only as scoped add-on later  
- **AI:** Cursor Agent as editor-in-chief workflow; Figma Dev Mode MCP when useful  

---

## 5. GTM (single channel, months 1–3)

**Only:** design agencies / brand studios that already ship Figma and need production overflow.

**Habit:** 3–5 async touches on 2–3 weekdays (morning pocket). Protect delivery hours.

**Outreach skeleton:**

> I help design agencies clear Next.js production overflow without adding calls to your week.  
> Locked Figma → live on Vercel via a monthly one-request queue (or a fixed Kickoff Sprint). Updates via Loom + board only.  
> If you have work stuck behind engineering capacity in the next 2–4 weeks, I can take one seat.

## 6. Roadmap (lean)

### Phase 1 — Prove the queue (now)

- Lock offer + docs (done in this repo)  
- Thin proof surface (1-page site or Notion + Loom) — no big brand project  
- Close **1** paying seat (sprint and/or subscription)  
- Refine SOPs from real delivery  

### Phase 1b — Raise and stabilize

- Raise price when demand hurts  
- Add a **second** seat only after one is easy  
- Prefer retainers over repeating cold sprint sales  

### Phase 2 — Leverage (later, decide then)

- Templates / section kits for agencies, or one product that reuses the assembly line  
- Not committed: Rank & Rent, legal form SaaS  

### Legal / tax (high level only)

- TN single-member LLC when ready to formalize  
- Disregarded entity early; S-Corp only with a CPA when profit consistently warrants it  
- Separate business banking + card for tools
